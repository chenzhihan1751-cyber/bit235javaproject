About this application

What was generated, which versions are used, and where the files live.

Stack

Spring Boot 4.1.2 on Java 21, built with Maven. The project was generated with Spring Initializr using three dependencies: Spring Web (MVC and the embedded Tomcat server), Thymeleaf (server side HTML templates) and Spring Boot DevTools (automatic restart while developing).

Layout

src/main/java holds TestwikiappApplication (the entry point) and WikiController (the C in MVC). src/main/resources/static holds the pages that do not need any server data, and src/main/resources/templates holds the Thymeleaf views used by /topics.

Why the HTML is generated

The brief asked for the HTML pages to be produced with an AI assistant, so the markup and the CSS in this project were generated that way and then reviewed and adjusted by hand. The pages share one small stylesheet instead of a CSS framework, which keeps the project readable.
